# HSC_simulation_practice_project_slim

This repository contains eidos code for running HSC simulations in slim, obtaining outputs, and python code for analyzing outputs. 

## hsc_simulation_code_eidos

This directory contains eidos code for running HSC simulations in slim. The file titled *neutral.eidos* contains code for running a neutral HSC simulation. *selection.eidos* contains code for running an HSC simulation with a beneficial mutation that increases the likelihood of symmetric division. 

*generate_output_code.md* contains instructions for modifying the eidos code to track certain properties while the simulation is running. Instructions are detailed in the file, and output options can be found within the file under the section **keywords**. 

## bash_code

This directory contains shell scripts for running in terminal. Use *sbatch* to submit the file (refer to *hpc_notes.md* for more information). 

## graphing_code

This directory contains python code for analyzing and graphing the output generated by running the simulation in slim. The name of the file corresponds to the output options in the **keywords** section of *generate_output_code.md*. Once the output has been generated, use the file with the matching name to graph. Make sure to modify the name of the file listed next to *read_csv* to use the correct file. 

## outputs

This directory contains files with outputs generated by running the simulation in slim. This directory is listed in *.gitignore*

## hpc_notes.md

This markdown file contains notes for submitting jobs to the HPC and using the terminal.
